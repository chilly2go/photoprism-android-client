- **Picker finds more of what's already uploaded:** files that are hidden in the library (couldn't be indexed) or have processing errors were offered as new, and the upload then skipped them as already in the library. The picker now finds them too.
- **Selecting many skips uploaded files:** with "Show already uploaded" on, selecting a day, selecting all, or dragging only picks the files that are missing. Tapping a single file still selects it, to upload it again on purpose.
- **Only allowed actions:** the app asks the library what the account may do and hides archive, delete, private, favorite, album and upload actions it wouldn't allow.
- Opening the picker takes a few seconds longer, as the library is asked about more kinds of files.
