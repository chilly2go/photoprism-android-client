- **Upload progress:** each file shows how much of it is uploaded, and the overall progress moves while large videos upload. After uploading, the queue says when files are being added to the library.
- **Faster picker:** what is known to be in the library is remembered, so opening the picker again doesn't check everything from scratch.
- **Select many at once:** the picker groups files by day. Tap a day to select all of it, or long-press a file and drag to select a range. Dragging near the edge scrolls.
- After adding files, the upload queue opens.
