- **Each file shows its state:** every file in the upload queue says what is happening to it: waiting, being checked, uploading with percent, uploaded and waiting, being added to the library, done, already there, or failed. While scrolling, a compact status with the overall progress and pause/resume stays on top.
- **Wi-Fi only by default:** uploads wait for Wi-Fi. "Also upload over mobile data" in the queue menu allows mobile data.
- **Pausing really pauses:** running uploads stop right away. Resuming right after pausing no longer uploads files twice.
- **Interrupted imports are finished:** if the connection drops after uploading, the files are added to the library next time instead of being uploaded again.
- **Shared files survive a restart:** files shared from other apps are copied until they are uploaded, so a restart of the phone doesn't make them unreadable.
- **Not allowed to upload:** for an account which may not upload, sharing to the app says so, and the queue marks the files with that reason instead of a general failure.
- **Logging out clears the queue,** so nothing is uploaded into the next account.
- **Picker:** smoother with thousands of files, also when dragging. Without access to photo locations it warns that it can't recognize uploaded photos, as they would be uploaded again without location, and turns off selecting many. If the server can't be reached, it retries and offers "Check again". Files which are not in the library are remembered too, so opening the picker asks the server less.
- **Correct dates for files without one:** if the library can't tell when a photo was taken (for example, a messenger image without metadata), the app sets the date known on the phone instead of the upload time. Files shared under a bare number, like "19422", get a name from their date and type.
- **Deleting works:** PhotoPrism only deletes photos which are in the archive, so "Delete" used to do nothing. Photos are now moved to the archive and then deleted forever.
- **Archive:** the new "Archive" in the menu lists archived photos. They can be restored or deleted forever there, one by one or selected together.
